# 审稿回复：意见、证据、修改相对应

## 逐条处理

保留 Reviewer 编号、Comment 编号及原意见。复合意见可拆成子问题，但不能漏掉不方便回答的要求；若原文缺失或 OCR 不清，标缺口，不猜补。

每条回复回答：审稿人关切什么，作者如何回应，有何实际修改或证据，修改位于何处。态度礼貌、表述直接，避免过度致谢挤占实质回答。

推荐英文格式：

```text
Reviewer [number], Comment [number]
Comment: [verbatim reviewer comment]
Response: [the response supported by the actual revision or evidence]
Changes in the manuscript: [actual revised text or a precise summary]
Location: [verified section/page/line, or MISSING marker]
```

页码、行号只有在当前版本确实核对过时才填写。没有稳定行号可用章节及可搜索的段落开头定位；连位置也未确定时标为待补，不能杜撰。

## 根据修改状态用语

- **已完成且可核对**：可以写 We have revised / added / conducted，后接实际内容和定位。
- **已有结果但尚未写入稿件**：解释证据本身；不要说已加入正文。中文说明指出还需完成哪项修改。
- **计划补充**：只能作为工作中的回复草稿，保留 `[MISSING: completed analysis and manuscript changes]`；不能让未来工作措辞掩盖尚未满足的返修要求。
- **无法完成或不同意**：解释实际限制，给出已有替代证据、可行替代方案或结论收缩。拟议方案与已完成方案分开。

## 常见意见

- **创新性或贡献不足**：具体比较重要相关工作与本文边界。避免以“方法很新”或其他审稿人赞同替代验证。
- **要求增加实验**：依据材料确认是否已经实施。没有结果时给出待完成事项，不承诺不存在的数据。
- **要求增加文献**：判断与所讨论问题的关系；只有在核对相关性和内容后形成支持性讨论，未经核验的条目单列说明。
- **格式、图表和语言**：明确改了什么与所在位置；只有查看过修改产物，才确认问题已经解决。

## 输出与自查

先给英文逐条回复，再给中文未完成事项与定位缺口。若实质修改未完成，明确“这是工作草稿，需完成所列修改后才能用于返修提交”。

检查每条意见均被回应，回复和实际稿件一致，完成式动词有证据支持，分歧围绕问题与证据，未把礼貌措辞当成回答本身。
