# 研究方法：让研究路径可以复核

## 按研究类型组织

方法的目的，是说明结果如何获得。优先写实际发生、且解释结果所必需的步骤。

- **理论研究**：定义问题、假设、符号和模型，说明推导关系与适用条件。不能把尚未完成的证明写成定理已证。
- **实证研究**：说明研究对象、数据来源、纳入排除条件、测量、处理方法和分析过程。样本和统计细节按实际材料报告。
- **工程或算法研究**：说明任务输入输出、系统或算法步骤、实现条件、训练或运行设置、对照方法和评估协议。按需区分方法设计与实验设置。

## 可复现细节

根据研究实际需要检查数据划分、预处理、关键参数、设备、软件版本、重复次数、随机性处理、指标定义和统计方法。没有提供的项目标缺口，不从常见实践或默认软件参数反推作者做法。

要区分作者改进部分与沿用部分。沿用方法在适当位置引用；把篇幅留给会影响结果或贡献判断的细节。

## 符号与公式

- 首次出现解释符号、含义和单位；复杂文稿可整理 Nomenclature 表。缩写首次给全称。
- 同一对象保持同一符号、名称、下标和单位；同一符号不要无说明地表达不同量。
- 保留数学含义、假设、索引范围和编号之间的依赖。公式用 LaTeX 表达；已有编号或标签优先保留，确需更改时同步正文引用。
- 发现符号冲突、量纲异常或推导缺步时指出具体位置。没有充分依据时不擅自修正成看似正确的公式。
- 只有与后续推导、实验或结果解释相关的公式才应占正文篇幅；基础知识不需要大段重述。

## 输出与自查

交付层次清楚的英文 Methods 或对应小节。必要时附符号清单和材料缺口，但不得把清单当成已补足实验记录。

自查：另一位研究者能否理解并按已描述路径复核工作；方法中出现的步骤是否确实实施；结果中使用的每个指标、数据集或条件是否在方法中有来源。
