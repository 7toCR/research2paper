## 原文原则、经验建议与新增约束

### 根据笔记提炼的执行原则

- 研究问题、方法、结果和贡献需要相互支持，文字表达不能替代证据。
- 方法有足够细节以便读者理解和复现；符号、单位和引用清楚一致。
- 结果讨论超越重复数据，交代解释、意义和边界；不回避不利结果。
- 图表应在正文中被准确引用；回复信逐条回应意见并定位真实修改。

### 保留为可调整建议

- 引言约占全文 10%、优先近五年文献、一般论文约 20 篇及综述 40–60 篇参考文献：均为笔记中的经验值，按领域、文章类型和期刊要求调整。
- 图用阿拉伯数字、表用罗马数字、图注在下表题在上、Figure 与 Fig.：按目标期刊指南和模板执行。
- 结论 1–2 段、摘要背景三句及方法 1–2 句：只是组织参考，不覆盖结构化摘要和字数限制。
- 审稿人数、初审或返修时间：仅是笔记中的流程介绍，不作为当前期刊的服务承诺或计划依据。
- 模拟和实验兼备、标题包含所有关键词、引言必须加图：不是所有研究都必须满足的条件，按实际论证需要使用。

### 为可靠执行新增或澄清

- **动笔顺序的来源边界**：笔记 II 的“时间顺序安排”明确方法 → 结果与讨论 → 结论，并要求文献阅读贯穿始终；VI 的 Abstract 明确引言、方法、结果讨论、结论都写好后再提炼摘要。本项目把引言定稿、全稿检查放入具体阶段，是执行编排，不声称这是原文逐项给出的唯一流程。
- **本次收紧早期摘要分支**：重制前的 README 及摘要规则允许“充分的真实材料也可支持早期摘要”，比原笔记宽。本次改为默认主体完成后写，只有用户明确要求时才输出标为“暂定草稿”的早期摘要，保留缺口并在主体完成后复核；这是项目分支，不替换原方法。
- **条件化解释的依据**：原文 V 第 1 项先要求查期刊指南；引言比例、文献数量／年份、表号与摘要句数等有些写作经验在笔记中语气较强。本项目统一限定为经验建议，服从研究类型和期刊要求；这一适用边界是整理时补充，不能声称原文已包含全部现代规则。
- “猜想和假设”转换为标明不确定性的解释及验证需求，不能为了自圆其说把推测写成因果结论。
- “改写”是重新组织论证和准确表达，不是机械替换同义词；专业术语和事实应保持稳定。
- “杜绝一图多投”不转化成“稍作修改即可复用”。复用图表须核对相关期刊政策、来源标注和许可；不能用改图掩盖重复发表或数据复用。
- 与审稿人有分歧时围绕问题和证据作答，其他审稿人的赞同不能替代对具体质疑的回答。
- 为防止生成内容越过材料边界，增加英文缺口标记、事实与解释区分、引用核验范围、真实修改状态及教学例子隔离。
- **教学示例**：足球命题、粉丝年龄比例及讲者论文实例用于说明表达方法，不进入用户论文的数据、方法或研究结论。
